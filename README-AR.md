# حروف مع المختبرات — النسخة المتصلة

هذه نسخة ويب عربية: رابط واحد للجميع، مع تحكم للمقدّم ومشاهدة مباشرة للمشاركين.

## ما الذي تحتاجه قبل النشر؟
- حساب Google لإنشاء مشروع Firebase.
- حساب GitHub.
- حساب Vercel (يمكن ربطه بـ GitHub).

## 1) إعداد Firebase
1. افتح https://console.firebase.google.com وأنشئ مشروعًا باسم horouf-ma3-almukhtabrat.
2. من Project settings أضف Web App وانسخ إعدادات Firebase.
3. من Build > Realtime Database أنشئ قاعدة بيانات.
4. من Authentication > Sign-in method فعّل Email/Password.
5. من Authentication > Users أضف مستخدمًا واحدًا للمقدّم (بريدًا وكلمة مرور)، ثم انسخ UID الخاص به.
6. افتح ملف `index.html`:
   - استبدل قيم `firebaseConfig` بقيم مشروعك.
   - استبدل `PASTE_HOST_UID` بالـ UID الخاص بالمقدّم.

## 2) قواعد قاعدة البيانات
من Realtime Database > Rules ضع القواعد التالية، مع استبدال HOST_UID بنفس UID للمقدّم:

```json
{
  "rules": {
    ".read": true,
    ".write": "auth != null && auth.uid === 'HOST_UID'"
  }
}
```

هذه القواعد تسمح للجميع بمشاهدة اللعبة، وتسمح فقط لحساب المقدّم المسجل بالكتابة. لا تشارك بيانات دخول المقدّم.

## 3) النشر عبر GitHub وVercel
1. أنشئ مستودع GitHub جديدًا.
2. ارفع `index.html` إلى جذر المستودع.
3. افتح https://vercel.com وسجّل الدخول باستخدام GitHub.
4. اختر Add New > Project ثم اختر المستودع.
5. اضغط Deploy. لا تحتاج إلى Build Command لموقع HTML ثابت.
6. سيعطيك Vercel رابطًا عامًا مثل `https://your-project.vercel.app`.
7. أرسل الرابط نفسه للجميع. أنت سجّل دخولك ببريد وكلمة مرور المقدّم؛ المشاركون يفتحون الرابط للمشاهدة فقط.

## تنبيه مهم
- هذا المشروع لا يتضمن إعدادات Firebase الحقيقية؛ يجب وضع إعدادات مشروعك وUID قبل التشغيل.
- رابط Vercel عام، لكن أدوات التحكم لا تظهر إلا لحساب المقدّم المطابق للـ UID.
- الأسئلة الحالية تجريبية وتحتاج مراجعة علمية وتحريرًا قبل اعتمادها في مسابقة رسمية.
- لا تضع كلمة مرور المقدّم داخل الكود أو تشاركها مع المشاركين.
